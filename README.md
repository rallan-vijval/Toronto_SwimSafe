# SwimSafe Toronto

This project analyzes Toronto's SwimSafe inspection data to examine how
inspection outcomes and recorded infractions vary across different types
of swimming facilities.

## Research question

How do inspection outcomes and infraction patterns vary across different
types of swimming facilities in Toronto?

## Project structure

- `data/raw/` — raw data downloaded from Toronto Open Data
- `scripts/` — R scripts used for data acquisition and analysis
- `figures/` — figures generated by the analysis
- `paper/` — Quarto paper

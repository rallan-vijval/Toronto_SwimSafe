Usage 2 - Understanding the unit of analysis:

User: The SwimSafe dataset has multiple rows for the same inspection because there can be multiple infractions. How should I aggregate the data so that each observation represents one inspection?

Chatgpt:
Explained that the raw records should be aggregated using the establishment, facility type, and inspection date. It suggested grouping by estName, type, and insDate and summarizing the inspection status and recorded infractions.

code:

inspections <- swimsafe %>%
  group_by(estName, type, insDate) %>%
  summarise(
    facilityName = first(facilityName),
    insStatus = case_when(
      any(insStatus == "Closed") ~ "Closed",
      any(insStatus == "Conditional Pass") ~ "Conditional Pass",
      any(insStatus == "Pass") ~ "Pass",
      TRUE ~ NA_character_
    ),
    infractions = sum(infType != "None", na.rm = TRUE),
    minor = sum(infType == "M - Minor", na.rm = TRUE),
    significant = sum(infType == "S - Significant", na.rm = TRUE),
    crucial = sum(infType == "C - Crucial", na.rm = TRUE),
    categories = n_distinct(infCategory[infCategory != "None"]),
    .groups = "drop"
  )


Usage 3 - Calculating inspection outcomes:

User: I want to compare the percentage of non-Pass inspections across Indoor Pool, Outdoor Pool, Spa Indoor, and Spa Outdoor. How can I calculate this in R?

Chatgpt:
Suggested grouping the inspection-level data by facility type and calculating the number and percentage of inspections that were not Pass.

code:

non_pass_by_type <- inspections %>%
  group_by(type) %>%
  summarise(
    inspections = n(),
    non_pass = sum(insStatus != "Pass"),
    non_pass_percent = 100 * non_pass / inspections
  )


Usage 4 - Comparing recorded infraction types:

User: I want to see the distribution of Minor, Significant, and Crucial recorded infractions for each facility type. How can I calculate the percentages?

Chatgpt:
Suggested first calculating the total number of each recorded infraction type within each facility type and then calculating the percentage within each facility type.

code:

severity_by_type <- inspections %>%
  group_by(type) %>%
  summarise(
    minor = sum(minor),
    significant = sum(significant),
    crucial = sum(crucial)
  ) %>%
  pivot_longer(
    cols = c(minor, significant, crucial),
    names_to = "severity",
    values_to = "n"
  ) %>%
  group_by(type) %>%
  mutate(
    percent = 100 * n / sum(n)
  ) %>%
  ungroup()

Usage 6 - Finding the most common specific deficiencies:

User: I want to find the top five specific deficiencies for each facility type.

Chatgpt:
Counting defDesc within each facility type, removing "None", and selecting the five most frequent deficiencies.

code:

top_deficiencies <- swimsafe %>%
  filter(defDesc != "None", !is.na(defDesc)) %>%
  count(type, defDesc, name = "n") %>%
  group_by(type) %>%
  slice_max(order_by = n, n = 5, with_ties = FALSE) %>%
  arrange(type, desc(n))

Usage 8 - Creating an inspection timeline:
